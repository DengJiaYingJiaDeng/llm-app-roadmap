# Day004 Linux 学习记录

## 文本处理
- grep：搜索文本
- find：查找文件和目录
- wc：统计行数、单词数和字节数
- sort 和 uniq：排序、去重与计数
- cut：提取字段
- sed：文本替换与行处理
- awk：按列处理与统计
- 管道 `|`：把前一个命令的输出交给后一个命令
- `>`：覆盖写入
- `>>`：追加写入
- `2>&1`：把标准错误重定向到标准输出

## 权限和环境变量
- chmod：修改权限
- export：设置当前 Shell 环境变量
- PATH：命令搜索路径
- which：查看命令来源

## 进程管理
- ps、pgrep：查看进程
- top、htop：查看资源占用
- jobs：查看后台作业
- kill：停止进程
- nohup：让任务在终端断开后继续运行
- tail -f：实时查看日志

## 远程与持久任务
- SSH：远程登录
- SCP：远程复制
- rsync：增量同步
- tmux：保存可断开并恢复的终端会话

## 最终验收
Windows 通过 SSH 连接 Ubuntu，在 tmux 中运行日志脚本。断开 SSH 后任务继续运行，重新连接后可以恢复会话并查看日志。
